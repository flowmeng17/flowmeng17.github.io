Ghost 安装指南

1

准备环境

Ghost 需要运行在 Node.js 环境中。请确保您的服务器或本地环境已安装 Node.js 16.x 或更高版本。

node --version
2

下载 Ghost

访问 Ghost 官方发布页面，根据您的操作系统（Linux, macOS, Windows）下载最新的 Ghost 安装包。

curl -L https://ghost.org/zip/ghost-latest.zip -o ghost.zip
3

配置与启动

解压下载的文件，运行安装脚本并设置管理员账户。Ghost CLI 工具将自动处理依赖项的安装。

npm install ghost-cli -g ghost install local

系统要求

✓
操作系统：Linux (Ubuntu 18.04+, Debian 9+, CentOS 7+), macOS, Windows
✓

✓
数据库：PostgreSQL (Ghost 5.0+ 默认使用 SQLite，建议生产环境使用 PostgreSQL)

常见问题 (FAQ)

Ghost 是完全免费开源的吗？
Ghost 的核心代码是开源的。您可以选择自行托管（下载源码部署），也可以使用 Ghost 官方提供的托管服务 Ghost(Pro)。
下载 Ghost 后如何配置域名？
在安装过程中，Ghost CLI 会询问您的站点 URL。您需要将域名的 DNS A 记录指向服务器的公网 IP 地址，并在安装完成后更新 SSL 证书。
支持哪些主题插件？
Ghost 提供官方主题市场，内置了多种专业主题。同时支持通过 npm 安装社区主题和插件，扩展功能如 SEO 优化、评论系统等。
如果下载失败怎么办？
请检查网络连接是否正常，确认 Node.js 版本是否符合要求。如果是国内用户访问官方下载源较慢，建议使用国内镜像源或 CDN 代理进行下载。
